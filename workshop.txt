title=[VSZ] No Indoor Respawn
description=[h1]No Indoor Respawn[/h1]
description=You know the drill. You set zombie respawn to off, fight your way through Rosewood and finally claim your first base in the fire station. You start hoarding supplies, planning your next runs... and suddenly there is a zombie in the toilet that was never there before.
description=
description=This mod stops a game bug from spawning zombies in rooms you have already visited. No more surprises.
description=
description=[h2]What is going on[/h2]
description=It is not respawn. The game populates a building the first time someone sees it and remembers that per room. Part of that record is stored by room index from the map files, and the index shifts whenever a game update changes the map. After an update the game thinks rooms you cleared long ago were never populated and fills them again. It only does that on floors near a connected player, so it can show up days after the update.
description=
description=[h2]What the mod does[/h2]
description=[list]
description=[*]Removes zombies the game re-creates on chunk load inside rooms that were already explored
description=[*]Repairs the broken room records so it stops happening
description=[*]Does nothing while zombie respawn is on
description=[*]Zombies that walk in through doors or windows are not touched
description=[/list]
description=
description=[h2]Notes[/h2]
description=[list]
description=[*]Build 42 (tested on 42.22.2), server-side, singleplayer and multiplayer
description=[*]Safe to add to an existing save
description=[*]A temporary fix until the game handles it itself
description=[/list]
